# Thematic Framework and Code Definitions

## Purpose and status
This file provides a concise public description of the seven themes reported in the two preprints. It is **not** the original operational codebook, a complete annotation manual, or a substitute for underlying coding records.

The themes were developed through Inductive Thematic Analysis as described in the manuscripts. This repository does not add decision rules, confidence scores, keyword lists, or coder instructions that are not reported in the source texts.

## Theme index

| Code | Theme | Short description |
|---|---|---|
| T01 | Dice Manipulation | Beliefs that dice outcomes are not genuinely random. |
| T02 | Pay-to-Win Mechanics | Beliefs that expenditure influences competitive outcomes. |
| T03 | Bot Opponents | Suspicions that purported human opponents are automated. |
| T04 | Connectivity Sabotage | Beliefs that connectivity problems disadvantage players. |
| T05 | Predetermined Outcomes | Beliefs that outcomes are decided independently of player actions. |
| T06 | Statistical Anomaly Reporting | Use of unusual sequences or numerical observations to support manipulation claims. |
| T07 | Support Dismissal / Perceived Support Dismissal | Perceptions that support responses dismiss or fail to address concerns. |

## Meta-theme structures

### Longitudinal manuscript
- Perceived Agency: T01, T05, T06
- Trust Erosion: T02, T03, T07
- Statistical Misinterpretation: T01, T05, T06

The same membership is printed for Perceived Agency and Statistical Misinterpretation. This apparent overlap is disclosed, not corrected.

### Cross-cultural manuscript
- Perceived Agency Erosion: T01, T04, T05
- Trust Erosion: T02, T03, T07
- Statistical Misinterpretation: T01, T05, T06

## Not included
The source manuscripts do not publish enough detail to reproduce a full operational codebook. This repository therefore does not invent exhaustive decision rules, keyword dictionaries, coder confidence labels, inter-coder reliability statistics, item-level annotations, or a complete audit trail.
